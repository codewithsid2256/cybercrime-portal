GitHub pe upload karne ka
sabse aasaan tareeka

Koi command nahi. Koi Git install nahi. Sirf mouse se click karke — 5 minute ka kaam.

5 minutes · Bilkul beginner ke liye

1ZIP file download karo

Jo file maine di hai — NCRP-Portal-GitHub-Upload.zip — usko apne computer me download karo (Downloads folder me chali jayegi).

Us file pe right click karo aur Extract All / Extract Here pe click karo.

ZAROORI: Ye step sabse zaroori hai. ZIP ko extract kiye bina upload nahi hoga. Extract karne ke baad ek folder banega jiska naam cybercrime-portal hoga. Uske andar ye cheezein dikhengi:
Folder
src  ·  public  ·  docs
Files
package.json · README.md · render.yaml
Agar aisi cheezein dikh rahi hain — to sab sahi hai.

2GitHub account banao

Browser me github.com kholo. Account nahi hai to Sign up pe click karo.

  • Email daalo
  • Password banao (kam se kam 8 characters)
  • Username socho — jaise aritra123
  • Email me aaya verification code daalo
Tip: Account pehle se hai to Sign in karke seedha Step 3 pe jao.

3Naya repository banao

Login karne ke baad, screen ke top-right corner me ek chhota + ka nishaan hai. Uspe click karo.

github.com (top-right corner)
+  →  New repository

Menu me New repository pe click karo. Ab ek form khulega — bilkul aise bharo:

Kya likha hai form meAapko kya karna hai
Repository nameType karo: cybercrime-portal
Description (optional)Chhod do khaali, ya likho: Cyber crime reporting portal prototype
Public / PrivatePublic select karo
Add a README fileNO — Tick mat karo

Sabse badi galti: "Add a README file" ya ".gitignore" me tick kar dena. Agar tick kiya to upload ke waqt conflict aayega. Teeno box khaali chhodo.

Sab bharne ke baad neeche Create repository pe click karo.

ab upload karenge

4Files upload karo (asli kaam)

Repository banne ke baad aapko ek khaali page dikhega jisme likha hoga "Quick setup". Us page pe ye link dhoondo:

uploading an existing file

Ye link neeli (blue) rang me hoga, page ke beech me. Uspe click karo.

Link nahi mil raha? Doosra tareeka: page ke top pe Add file button hai → uspe click karo → Upload files select karo.

Ab ek badi box khulegi jisme likha hoga "Drag files here to add them to your repository". Ab ye karo:

  1. Apna cybercrime-portal folder kholo (jo Step 1 me extract kiya tha)
  2. Ctrl + A dabao (Windows) ya Cmd + A (Mac) — sab kuch select ho jayega
  3. Sab kuch drag karke browser ke us box me chhod do
Drag files here to add them to your repository
↑   Yahan files chhodo
(55 files upload hongi)
ZAROORI: Agar folder drag nahi ho raha: pehle cybercrime-portal folder ke andar jao, phir Ctrl+A karo, phir drag karo. Folder ke andar ki cheezein drag karni hain, folder khud nahi.

Files upload hone me 1-2 minute lagenge (10 MB hai). Progress bar dikhega. Wait karo.

5Commit karo (yaani save karo)

Files upload hone ke baad, page thoda neeche scroll karo. Wahan ye dikhega:

Commit changes
Add files via upload
○ Commit directly to the main branch
Commit changes

Kuch likhna zaroori nahi — jo likha hai theek hai. Bas Commit changes pe click karo.

Bas! Aapki files GitHub pe chali gayin.

GitHub ka kaam ho gaya!

Ab browser me apni repository kholiye — saari files dikhni chahiye. Aapka link hoga aisa:

https://github.com/aapka-username/cybercrime-portal

Jab aisa page dikhe jisme files ki list ho aur README.md ka content neeche dikh raha ho — to sab sahi hai. Ab Render pe jayenge.

ab live karenge

6Render account banao

Naye tab me render.com kholo.

  1. Get Started pe click karo
  2. GitHub wala button select karo (Google/email nahi — GitHub hi, kyunki code wahan hai)
  3. GitHub permission maangega → Authorize Render pe click karo
Achhi khabar: Render me credit card nahi chahiye free plan ke liye. Bilkul free hai.

7Web Service banao

Render dashboard pe pahunchne ke baad, top-right me + New pe click karo → Web Service select karo.

Ab "Build and deploy from a Git repository" wala option select karo → Next.

List me apni repo cybercrime-portal dikhegi. Uske aage Connect pe click karo.

ZAROORI: Repo nahi dikh rahi? "Configure account" ya "GitHub" link pe click karke repo ka access allow karo. Ya "Public Git repository" tab me apna GitHub URL paste kar do.

Ab ek form khulega. Sirf ye 5 cheezein bharo, baaki chhod do:

FieldKya daalna hai
Namencrp-prototype
RegionSingapore (India se sabse paas)
Branchmain (apne aap aa jayega)
Build Commandnpm install
Start Commandnpm start

Neeche Instance Type me Free select karo.

Sabse neeche Create Web Service pe click karo.

OKDeploy ke baad 3 chhote kaam

  • Link kisi ko bhejo — WhatsApp pe bhej ke mobile me check karo. 15 minute idle ke baad pehli baar khulne me 30-60 sec lag sakta hai. Ye normal hai (free plan).
  • README me link daalo — GitHub repo kholo → README.md pe click → pencil (edit) icon → sabse upar apna Render link add karo → Commit.
  • Demo disclaimer mat hatao — footer me "DEMONSTRATION PROTOTYPE" likha hai. Ye zaroori hai — project sarkari nahi hai.
